# Why One Layer Suffices: The IIR/FIR Analogy

## The Core Question

When the input to a transformer block is already fully contextualized — carrying the full context of all preceding tokens — how many layers are needed to process it?

## Autoregressive Sufficient Statistic

Assume the data is generated by a stationary autoregressive process. The optimal predictor at position $t$ depends on the past only through a sufficient statistic $s_t \in \mathbb{R}^d$ satisfying:

$$s_t = h(s_{t-1}, x_t)$$

for some update function $h$. The prediction is $\hat{x}_{t+1} = f(s_t)$.

### Context-ready: one step suffices

If the block output $z_{t-1}$ encodes $s_{t-1}$, and the correction injects this into position $t$'s input, then the block at position $t$ needs only to compute the single-step update $z_t = h(z_{t-1}, e_t)$. This is one application of the block — $D$ layers — regardless of sequence length. Even $D = 1$ suffices if $h$ is realizable by a single attention + FFN layer.

### Standard transformer: depth for reconstruction

Without the correction, a standard transformer at position $t$ must reconstruct the sufficient statistic from the raw sequence:

$$s_t = h(h(\ldots h(s_0, x_1)\ldots, x_{t-1}), x_t)$$

This requires composing $h$ a total of $t$ times. Each transformer layer can perform approximately one composition, so a fixed-depth $N$-layer transformer can only track $s_t$ for $t \leq N$. This is exactly the TC^0 limitation.

### The model IS the process

If we assume the input is generated by the same process that we are modeling — i.e., the block + correction defines the autoregressive process — then the argument becomes almost definitional:

- $z_{t-1}$ is the process's own state after seeing tokens $0, \ldots, t-1$
- It already encodes everything the model considers relevant about the past
- Contextualizing the new token $e_t$ requires exactly one application of the block: compute $z_t = B(e_t + C(z_{t-1}, e_t))$
- One step, regardless of sequence length

The number of layers needed is $D$ (the block depth), independent of $t$.

## Separation of Depth Sources

A standard $N$-layer transformer uses its depth for two distinct purposes:

1. **Context propagation**: moving information across positions via attention hops
2. **Mapping complexity**: computing a complex nonlinear function of the already-aggregated context

A standard transformer conflates these — every layer does both, and $N$ must be large enough for whichever is harder. The context-ready architecture separates them:
- **(1)** is handled by the correction chain over the sequence (the recurrence)
- **(2)** is handled by the $D$-layer block

If the layers in a standard transformer are purely for context propagation — as in the pointer-chasing task, where each level requires one additional hop — then $D = 1$ suffices. The correction chain handles all the propagation, and a single layer computes the final mapping.

If the layers are also needed for mapping complexity — approximating a nonlinear function that requires depth even when the context is already available — then $D > 1$ is needed. The block depth $D$ controls the expressiveness of the single-step update $h$, while the correction chain still handles context propagation regardless of $D$.

On the pointer-chasing task, where the computation is pure context propagation, $D = 1$ suffices — confirming that the correction chain handles propagation entirely. For language modeling, $D = 1$ beats $N = 6$ with sufficient block size and $K$, and $D = x$ beats $N = x$ at every depth tested. Whether $D > 1$ is needed for language tasks due to mapping complexity, or simply because the block size (and hence the correction chain length) was not large enough, remains an open question — we have not tested large block sizes at $D > 1$.

## The IIR/FIR Analogy

This separation maps precisely to the classical distinction between IIR and FIR filters in signal processing.

### Standard N-layer transformer = FIR filter of order N

An FIR (Finite Impulse Response) filter computes its output from a finite window of past inputs:

$$y_t = \sum_{k=0}^{N-1} b_k \, x_{t-k}$$

No feedback, no recursion. The impulse response has finite length $N$.

A standard $N$-layer transformer is analogous: it processes the raw input sequence $(e_0, \ldots, e_t)$ through $N$ layers. Each layer propagates context one hop via attention. After $N$ layers, information can travel at most $N$ hops. The effective "impulse response" is bounded by the depth $N$.

To approximate a process with long-range dependencies (slowly decaying impulse response), an FIR filter needs many taps — and a standard transformer needs many layers.

### Context-ready transformer at inference = IIR filter

An IIR (Infinite Impulse Response) filter uses feedback — its own past outputs — to compute the current output:

$$y_t = \sum_{k=1}^{p} a_k \, y_{t-k} + \sum_{k=0}^{q} b_k \, x_{t-k}$$

The recursion gives it infinite effective memory: a few coefficients can capture what would require an FIR of arbitrarily many taps.

The context-ready transformer at sequential inference has exactly this structure: the correction creates a feedback loop $z_t = f(z_{t-1}, e_t)$. The impulse response is infinite — information from position 0 influences position $t$ for any $t$, propagated through the recursive correction chain. A few parameters (one block layer + correction FFN) achieve what would require arbitrarily many FIR taps (transformer layers).

### The classical result

In signal processing, a well-known result is that an IIR filter of order $p$ can be equivalent to an FIR filter of infinite length. The canonical example: a first-order IIR filter $y_t = a \, y_{t-1} + b \, x_t$ (two coefficients) is equivalent to the FIR filter $y_t = b \sum_{k=0}^{\infty} a^k x_{t-k}$ (infinitely many taps).

Similarly, a $D = 1$ context-ready transformer (first-order IIR: $z_t = f(z_{t-1}, e_t)$) can have effective depth equal to the sequence length — matching what would require a standard transformer of arbitrary depth.

### Inference is always IIR — even with finite $K$ training

A critical property of the context-ready architecture: **inference is always IIR, regardless of the $K$ used during training.** The non-cumulative + past-only structure guarantees that sequential inference produces the exact fixed-point correction (Theorem 2 in the paper). The correction chain runs for the full sequence length, giving effective depth equal to $T$ — not $K$.

This is confirmed empirically: sequential $K = 1$ inference matches parallel $K = 10$ at every configuration tested (Table 6 in the paper). A model trained with $K = 5$ achieves infinite effective depth at inference.

### Training $K$ = designing the IIR coefficients

$K$ during training controls the depth of the gradient computation, which affects how well the model *learns* to exploit the IIR structure — not what it can do at inference. Larger $K$ means gradients flow through more feedback steps, allowing the model to learn correction functions that exploit longer-range recursive dependencies:

- $K = 5$: sufficient for the model to learn effective corrections at $D \geq 2$
- $K = 10$: needed for $D = 1$ to learn to exploit the full recurrent depth
- BPTT ($K = T$): gradients flow through the entire sequence — needed for pointer chasing

The analogy to IIR filter design: $K$ is the number of terms used to compute the gradient of the filter coefficients. A small $K$ may not expose the optimizer to the long-range behavior of the filter, so the learned coefficients may not fully exploit the IIR's infinite impulse response. But even with small $K$, the deployed filter is still IIR — it runs recursively over the full input.

## Experimental Confirmation

### Pointer chasing = measuring the impulse response length

The pointer-chasing experiment directly measures the effective impulse response:

- An $N$-layer transformer (FIR of order $N$) solves approximately $N$ levels of composition — its impulse response is length $N$
- The $D = 1$ context-ready model (IIR) solves all levels — its impulse response is unbounded

This is the staircase: FIR is depth-limited, IIR is not.

### Correction efficiency = IIR coefficients replacing FIR taps

At $C = 1024$, the correction FFN costs $8C^2$ FLOPs but provides the benefit of two additional transformer layers ($24C^2$). This is the IIR advantage: a small number of feedback coefficients (the correction FFN) replaces many feedforward taps (transformer layers).

### D=1 beats N=6 = first-order IIR matching 6th-order FIR

With $K = 10$ training at block size 1024, a single-layer context-ready model ($D = 1$) beats a 6-layer standard transformer at FLOP parity. A first-order IIR system (one feedback coefficient) matches a 6th-order FIR system (six taps).

### Width scaling = IIR precision

The advantage grows with width (9.6% at $C = 256$ to 16.5% at $C = 1024$). Wider embeddings give the IIR filter higher-precision state representation, allowing the feedback to carry more information — analogous to increasing the bit width of an IIR filter's internal state.

## Formal Proposition (for the paper)

**Proposition (IIR/FIR separation).** Let the data be generated by a stationary autoregressive process with sufficient statistic $s_t = h(s_{t-1}, x_t)$, where $h$ is realizable by a $D$-layer transformer block of width $C$.

(a) A context-ready transformer with block depth $D$, trained with any finite $K$, computes the exact sufficient statistic at sequential inference: the non-cumulative + past-only structure guarantees that the correction chain applies $h$ once per position, so $z_t = h(z_{t-1}, e_t)$ for all $t$, with effective depth equal to the sequence length. Training with finite $K$ is sufficient to learn $h$; infinite depth is realized at inference regardless of $K$. If $h$ requires only one layer (context propagation dominates), $D = 1$ suffices. If $h$ requires $D$ layers (mapping complexity dominates), the block provides this depth while the correction chain still handles propagation.

(b) A standard $N$-layer transformer must use its $N$ layers for both context propagation and mapping complexity. It can compose $h$ at most $N$ times, so the effective impulse response is bounded by $N$. The layers spent on propagation are unavailable for mapping, and vice versa.

(c) The context-ready architecture separates the two: context propagation is handled by the correction chain (IIR feedback, unbounded depth), and mapping complexity is handled by the $D$-layer block. A standard transformer conflates both into a single depth budget $N$, so it requires $N \geq N_{\text{prop}} + N_{\text{map}}$, while the context-ready transformer requires only $D \geq N_{\text{map}}$.

**Proof sketch.**

Part (a): At sequential inference, position 0 receives correction $C(z_{-1}, e_0) = C(\mathbf{0}, e_0)$ and produces $z_0 = B(e_0 + C(\mathbf{0}, e_0))$. Position 1 receives $C(z_0, e_1)$ and produces $z_1 = B(e_1 + C(z_0, e_1))$. By induction, $z_t$ depends on all of $e_0, \ldots, e_t$ through the chain $z_0 \to z_1 \to \cdots \to z_t$. If $B \circ C$ realizes $h$, then $z_t = s_t$ exactly.

Part (b): In a standard transformer, layer $\ell$ at position $t$ attends to layer $(\ell-1)$ representations. Layer 1 sees raw embeddings and computes $h(s_0, x_t)$ via attention. Layer 2 composes to get $h(h(\cdot), \cdot)$. After $N$ layers, at most $N$ compositions of $h$ are computed. For $t > N$, the suffix $s_t$ cannot be reached.

Part (c): Follows from (a) and (b). A standard transformer has a single depth budget $N$ shared between propagation and mapping: $N \geq N_{\text{prop}} + N_{\text{map}}$. The context-ready architecture offloads propagation to the correction chain (unbounded, IIR), so the block depth need only satisfy $D \geq N_{\text{map}}$. When propagation dominates ($N_{\text{prop}} \gg N_{\text{map}}$), the savings are largest: $D \ll N$. When mapping dominates ($N_{\text{map}} \gg N_{\text{prop}}$), the savings are smaller but the correction chain still eliminates the propagation cost.
