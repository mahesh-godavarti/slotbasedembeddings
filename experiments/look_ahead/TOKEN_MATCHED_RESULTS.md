**Pattern**:
1. D starts behind (initial disruption from K=2-5 training)
2. D recovers and crosses over N
3. After crossover, the gap widens -- D gets progressively better relative to N
4. Crossover takes longer at larger N (more tokens needed)
5. The final gap is smaller at larger N (diminishing returns)

## Claim 2: Practical recipe -- convert from the best roformer

To get the best D=x model quickly, convert from the best available N=x roformer and fine-tune. Always use the most-trained roformer available.

### Evidence: fresh conversion vs continued fine-tune

At the end of all training rounds:

| Model | Source | Final PPL | Total tokens |
|---|---|---|---|

| | | | |
| **D=2 fresh** | N=2 @ 1,227M | **67.64** | 1,636M |
| **D=2 cont3** | N=2 @ 409M + 715M FT | **66.14** | 1,124M |
| N=2 (cycle 3) | -- | 72.83 | 1,227M |
| | | | |
| **D=3 fresh** | N=3 @ 1,227M | **59.78** | 1,636M |
| **D=3 cont3** | N=3 @ 409M + 715M FT | **59.41** | 1,124M |
| N=3 (cycle 3) | -- | 61.60 | 1,227M |
| | | | |
| **D=6 fresh** | N=6 @ 1,227M | **50.96** | 1,636M |
| **D=6 cont3** | N=6 @ 409M + 715M FT | **52.25** | 1,124M |
| N=6 (cycle 3) | -- | 52.47 | 1,227M |

### Observations

1. **Fresh conversion adapts faster** within each round. D=2 fresh reached 67.64 in 409M FT tokens. D=2 cont3 needed 715M FT tokens to reach 66.14.

2. **Continued fine-tuning eventually catches up or beats fresh** (D=1, D=2, D=3 cont3 all beat fresh). More total fine-tune tokens overcome the worse starting point.

3. **D=6 fresh beat D=6 cont3** -- the only case where fresh won. At larger D, the better starting point matters more because recovery from disruption is slower.

4. **Practical recipe**: If you have a well-trained roformer, convert it. If you're going to do a lot of fine-tuning anyway, it doesn't matter as much which roformer you start from -- the cont path catches up.

## Key takeaways

1. **D=x is strictly better than N=x at matched tokens.** Proven at D=1,2,3,6. The gap widens with more training at every scale tested.

2. **The advantage is larger at smaller N.** D=1 gains 34 PPL over N=1. D=6 gains 0.7 PPL over N=6. The correction mechanism has more room to help when there are fewer layers.

3. **Crossover takes longer at larger N.** D=1 crosses at 424M tokens, D=6 at 1,032M tokens. Larger models need more training for the correction mechanism to learn.

4. **D=12 beats N=13 at fewer inference FLOPs.** The look-ahead architecture provides more than one layer's worth of improvement (1.20 PPL gain vs 0.59 PPL for an extra layer) with fewer additional FLOPs (8C^2 vs 12C^2).

5. **Converting a pretrained roformer is the fastest path.** Fine-tune at K=2-5 for 20-30% of pretraining tokens. The better the source roformer, the faster the conversion.
